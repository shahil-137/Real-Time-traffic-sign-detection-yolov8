Capabilities

Everything you need for road sign intelligence

01
◈
Real-Time Detection

YOLOv8 inference at 1024px resolution with FP16 precision. Detects signs frame-by-frame from live webcam feed with bounding boxes and confidence scores.

02
♪
Voice Alerts

High-confidence detections (≥0.75) trigger clear voice announcements via gTTS + pygame. Single audio queue prevents overlapping speech.

03
⊞
Stability Filtering

Signs must appear in 4 consecutive frames before an alert fires. Eliminates false positives from momentary flickers or misdetections.

04
◎
Confidence Tiers

Green boxes for high-confidence detections (speaks), orange for low-confidence (visual only). Dual threshold system keeps noise out.

05
⟳
Smart Cooldown

4-second cooldown per sign prevents repetitive announcements. Only the single highest-confidence stable sign is announced per frame cycle.

06
▦
Live Dashboard

Real-time FPS counter, detection log, confidence metrics, and uptime tracking. Flask-powered web interface accessible from any browser.
